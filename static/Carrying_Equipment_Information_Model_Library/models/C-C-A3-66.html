5.3.6 信息模型基础属性
信息模型名称干线交叉口信号控制信息模型
逻辑阶段控制
实体层级中心云
自主化水平A3
信息模型编号C-C-A3-66
信息模型功能描述在自主化水平为A3的场景中，中心云与边缘计算单元提取交通参与者与路网运行的关键信息，决策是否调节各信号交叉口之间的相位差，使干道上按照或者是接近设计车速的车辆，获得尽可能不停顿的通行权
信息模型服务场景城市路网区域协调信号控制、交通拥堵溯源、交通流量监测与优化、交叉口粒流协同控制等
上游信息模型编号交叉口排队溢出疏解信息模型（D-E-A3-46）、应急车辆优先信息模型（D-C-A3-40）、公交信号优先信息模型（D-C-A3-67）
下游信息模型编号无（本模型为控制执行或信息输出终端模型）
交付时间2026/08/21
