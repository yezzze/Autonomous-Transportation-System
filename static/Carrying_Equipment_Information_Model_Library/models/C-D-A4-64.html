5.3.6 信息模型基础属性
信息模型名称协作式车辆汇入信息模型
逻辑阶段控制
实体层级端侧
自主化水平A4
信息模型编号C-D-A4-64
信息模型功能描述自主化水平为A4时，协作式车辆汇入信息模型面向高度自动化多车动态合流过程，以汇入车辆及目标车道协作车辆为控制对象，接收V2V/V2I交换的多车实时状态、意图与协作信息，并接收车辆跟驰信息模型形成的建议速度、期望加速度、安全跟驰间距和短时状态预测结果，围绕目标间隙、汇入时机和协作次序连续滚动执行多车纵向协同控制，构造并维持稳定的汇入窗口；当交通状态或安全约束发生变化时，系统自主调整控制目标，必要时中止或降级当前协作过程。
信息模型服务场景高速公路及城市快速路高密度匝道汇入、车道封闭动态合流、多车交替通行和车队重组等需要连续自主协同控制的场景。
