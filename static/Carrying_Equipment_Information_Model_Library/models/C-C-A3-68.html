5.3.6 信息模型基础属性
信息模型名称公交信号优先自适应补偿信息模型
逻辑阶段控制
实体层级中心云
自主化水平A3
信息模型编号C-C-A3-68
信息模型功能描述自主化水平为 A3 时，道路交通系统包含 L3、L4、L5 级自动驾驶车辆与人类驾驶车辆，边缘计算与中心云具备一定的决策与控制能力。公交信号优先自适应补偿信息模型运行于中心云计算单元，当评价结果表明非优先相位影响超过容许阈值或优先效果偏离预期时，模型识别需补偿的相位，在最小绿灯时间、相位顺序与清空安全约束下计算后续周期相位补偿量和实施时序，恢复优先控制占用的绿灯时间。
信息模型服务场景公交信号优先、城市路网区域协调信号控制等。
上游信息模型编号交通信号感知信息模型（P-E-A3-3）、交通流感知信息模型（P-E-A3-4）、路网通信I2N信息模型（T-E-A3-20）、公交信号优先信息模型（D-C-A3-67）
下游信息模型编号无（本模型为控制执行或信息输出终端模型）
