自主化水平A3
信息模型编号C-C-A3-96
信息模型功能描述自主化水平为A3时，中心云依据轨道站点上传的激增态势与外部疏散需求，在常态接驳运力配置基础上生成并下发应急疏散协同调度指令，包括应急接驳专线开行、备用运力抽调与投放、出租网约定向引导，并依据接驳区容量与运力到达时刻确定分批疏散放行时序。A3阶段常规疏散指令由系统生成并下发执行，跨线路跨场站的大范围运力抽调与高等级应急响应由管理人员确认。
信息模型服务场景轨道激增客流的多方式运输自组织调度。
上游信息模型编号轨道站点客流与列车运行状态感知信息模型（P-E-A3-90）、轨道客流激增态势识别信息模型（R-E-A3-93）、轨道-道路跨域协同交互信息模型（T-E-A3-94）、轨道接驳多方式运力一体化配置信息模型（D-C-A3-95）
