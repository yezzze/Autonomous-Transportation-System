使用方法：
1. 将 scenarios.html 复制到你的模型库根目录，覆盖原 scenarios.html。
2. 将 scenarios 文件夹复制到你的模型库根目录，覆盖/合并原 scenarios 文件夹。
3. 将 assets/uml 文件夹复制到你的模型库根目录，覆盖/合并原 assets/uml 文件夹。
4. 两张 SVG 已统一命名为：
   - assets/uml/bus-priority.svg
   - assets/uml/intersection-safety.svg
5. 两个详情页路径分别为：
   - scenarios/bus-priority.html
   - scenarios/intersection-safety.html
6. 如果某些 models/*.html 链接暂时打不开，说明对应模型详情页还未生成；不影响 UML 场景页显示。
