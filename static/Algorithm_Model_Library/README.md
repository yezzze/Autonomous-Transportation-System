# 自主式交通系统协同计算基础算法模型库前端

## 文件说明

- `index.html`：模型库首页，支持搜索、展开/收起、Excel 导入、路径高亮。
- `model.html`：模型详情页，双击首页模型节点进入。
- `assets/`：页面样式和交互脚本。
- `data/`：默认模型数据与仓库入口 URL 映射。
- `input/课题一协同计算模型清单v5.xlsx`：原始模型清单。
- `input/model_import_template_with_links.xlsx`：模型信息与仓库入口 URL 单表模板，后续建议按此格式维护。
- `input/model_import_130_with_links.xlsx`：当前 130 个模型与仓库入口 URL 合并后的可直接导入 Excel。
- `input/model_import_validation_150.xlsx`：150 条模型导入验证表，已将仓库入口 URL 放入同一张表。
- `input/model_repo_links.xlsx`：原仓库入口 URL 来源表，作为历史来源参考。
- `screenshots/`：当前验收截图。

## 使用方式

建议在本文件夹内启动本地静态服务后访问：

```bash
python3 -m http.server 8765
```

然后打开：

```text
http://127.0.0.1:8765/index.html
```

也可以直接打开 `index.html`，但本地服务方式更接近正常页面访问环境。

## 当前说明

- 首页单击模型节点显示从 0 级节点到模型本身的高亮路径，再次单击可退出路径高亮。
- 首页双击模型节点进入详情页；在路径高亮状态下双击也可以进入详情页。
- 从详情页返回主页后，会保留最后的搜索、展开、高亮和画布位置状态。
- 页面上传新的 Excel 后，会用新 Excel 数据重建模型树；新增模型会显示，删除模型会从当前导入数据中移除。
- 仓库链接优先读取导入 Excel 中的 `仓库入口URL`，其次读取已有链接映射；两者均未提供时，自动按固定前缀和小写模型编号生成链接（例如 `1-4-J-200` 对应 `http://10.112.76.79:8080/#path=algo1-4-j-200`）。
