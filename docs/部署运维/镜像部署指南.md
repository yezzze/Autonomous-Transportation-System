# LangManus Docker 镜像部署指南

## 📦 镜像获取与加载

### 1. 导出镜像（构建者操作）

```bash
# 导出镜像到 tar 文件
docker save langmanus-web-ui:latest -o langmanus-web-ui.tar

# 压缩（可选，减小文件大小）
gzip langmanus-web-ui.tar
# 生成文件：langmanus-web-ui.tar.gz
```

### 2. 加载镜像（使用者操作）

```bash
# 如果是压缩文件，先解压
gunzip langmanus-web-ui.tar.gz

# 加载镜像
docker load -i langmanus-web-ui.tar

# 验证镜像已加载
docker images | grep langmanus
```

## ⚙️ 配置文件准备

### 1. 创建项目目录

```bash
mkdir -p langmanus-deploy
cd langmanus-deploy

# 创建必要的子目录
mkdir -p config logs data
```

### 2. 配置 `.env` 文件

创建 `.env` 文件（**必需**）：

```bash
cat > .env << 'EOF'
# ===== LLM 配置 =====

# 推理模型（用于 Planner）
REASONING_API_KEY=your-api-key-here
REASONING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
REASONING_MODEL=qwen-flash

# 基础模型（用于 Coordinator/Supervisor/Reporter）
BASIC_API_KEY=your-api-key-here
BASIC_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
BASIC_MODEL=qwen-flash

# 视觉模型（用于 Browser Agent）
VL_API_KEY=your-api-key-here
VL_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
VL_MODEL=qwen2.5-vl-72b-instruct

# ===== 应用配置 =====
DEBUG=True
APP_ENV=development

# ===== LLM 智能体模拟器配置 =====
USE_LLM_SIMULATOR=true
LLM_SIMULATOR_MODEL=basic

# ===== 第三方服务 =====
TAVILY_API_KEY=your-tavily-key-here
EOF
```

**⚠️ 必须修改的配置项：**
- `REASONING_API_KEY` - 你的 LLM API Key
- `BASIC_API_KEY` - 你的 LLM API Key（可与上面相同）
- `TAVILY_API_KEY` - Tavily 搜索 API Key（可选，用于搜索功能）

### 3. 配置 `config/agent_registry.json` 文件

创建 Agent 注册表配置（**必需**）：

```bash
cat > config/agent_registry.json << 'EOF'
{
  "version": "1.0",
  "description": "LangManus Agent Registry Configuration",
  "registry_type": "file",
  "agents": [
    {
      "id": "search_agent_001",
      "ip": "127.0.0.1",
      "port": 8080,
      "capability": "search",
      "status": "online",
      "description": "搜索 Agent",
      "enabled": true,
      "priority": 10,
      "tags": ["search", "web"],
      "node_name": "localhost"
    },
    {
      "id": "compute_agent_001",
      "ip": "192.168.1.102",
      "port": 8080,
      "capability": "compute",
      "status": "online",
      "description": "计算 Agent",
      "enabled": true,
      "priority": 8,
      "tags": ["compute", "math"],
      "node_name": "node-02"
    },
    {
      "id": "nlp_agent_001",
      "ip": "192.168.1.103",
      "port": 8080,
      "capability": "nlp",
      "status": "online",
      "description": "NLP Agent",
      "enabled": true,
      "priority": 9,
      "tags": ["nlp", "text"],
      "node_name": "node-03"
    }
  ]
}
EOF
```

**⚠️ 必须修改的配置项：**
- `ip` - 改为你的 Agent 节点真实 IP 地址
- `port` - 改为 Agent 服务的端口
- `enabled` - 设为 `true` 启用，`false` 禁用
- 可根据需要增删 Agent

### 4. 创建 `docker-compose.yml` 文件

```bash
cat > docker-compose.yml << 'EOF'
services:
  web-ui:
    image: langmanus-web-ui:latest
    container_name: langmanus-web-ui
    ports:
      - "8000:8000"
    volumes:
      - ./config:/app/config
      - ./logs:/app/logs
      - ./data:/app/data
      - ./.env:/app/.env
    env_file:
      - .env
    restart: unless-stopped
EOF
```

## 🚀 启动服务

### 1. 目录结构检查

确认目录结构如下：

```
langmanus-deploy/
├── .env                        # ✅ 环境变量配置
├── docker-compose.yml          # ✅ Docker 编排文件
├── langmanus-web-ui.tar        # ✅ 镜像文件
├── config/
│   └── agent_registry.json     # ✅ Agent 注册表
├── logs/                       # 自动创建
└── data/                       # 自动创建
```

### 2. 启动容器

```bash
# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f web-ui
```

### 3. 访问 Web UI

打开浏览器访问：**http://localhost:8000**

## 🔧 配置修改（运行时）

### 修改 API Key

```bash
# 1. 编辑 .env 文件
vim .env

# 2. 修改 API Key
REASONING_API_KEY=new-key-here

# 3. 重启容器
docker-compose restart web-ui
```

### 修改 Agent 配置

```bash
# 1. 编辑 agent_registry.json
vim config/agent_registry.json

# 2. 修改 IP、端口、启用状态等
# 例如：修改某个 Agent 的 IP
{
  "id": "search_agent_001",
  "ip": "192.168.1.100",  # ← 修改这里
  "enabled": true         # ← 或修改启用状态
}

# 3. 重启容器
docker-compose restart web-ui
```

## 🛠️ 故障排查

### 1. 容器无法启动

```bash
# 查看详细日志
docker-compose logs web-ui

# 常见问题：
# - 端口 8000 被占用 → lsof -ti:8000 | xargs kill -9
# - .env 文件不存在 → 检查文件是否存在
# - 配置文件格式错误 → 检查 JSON 语法
```

### 2. 无法访问 Web UI

```bash
# 检查容器是否运行
docker ps | grep langmanus

# 检查端口映射
docker port langmanus-web-ui

# 测试本地访问
curl http://localhost:8000
```

### 3. Agent 连接失败

- 检查 `config/agent_registry.json` 中的 IP 和端口是否正确
- 确保 Agent 服务已在对应节点启动
- 如果 Agent 不存在，系统会自动降级到 LLM 模拟器

## 🎯 快速启动脚本

创建一键启动脚本：

```bash
cat > start.sh << 'EOF'
#!/bin/bash
set -e

echo "🚀 启动 LangManus..."

# 检查配置文件
if [ ! -f .env ]; then
    echo "❌ 未找到 .env 文件，请先创建配置"
    exit 1
fi

if [ ! -f config/agent_registry.json ]; then
    echo "❌ 未找到 agent_registry.json 文件，请先创建配置"
    exit 1
fi

# 启动服务
echo "📦 启动容器..."
docker-compose up -d

# 等待启动
sleep 3

# 显示日志
echo "📊 服务日志："
docker-compose logs --tail=20 web-ui

echo ""
echo "✅ 服务已启动！"
echo "📊 访问地址: http://localhost:8000"
EOF

chmod +x start.sh

# 使用方式
./start.sh
```

## 📝 配置模板下载

如果配置文件丢失，可以使用以下命令从容器中提取模板：

```bash
# 提取 .env 模板
docker run --rm langmanus-web-ui:latest cat /app/.env.example > .env

# 提取 agent_registry.json 模板
docker run --rm langmanus-web-ui:latest cat /app/config/agent_registry.json.example > config/agent_registry.json
```

## 🎉 总结

### 核心步骤

1. ✅ 加载镜像：`docker load -i langmanus-web-ui.tar`
2. ✅ 创建目录：`mkdir -p config logs data`
3. ✅ 配置 `.env`：填入 API Key
4. ✅ 配置 `config/agent_registry.json`：填入 Agent IP
5. ✅ 启动服务：`docker-compose up -d`
6. ✅ 访问：http://localhost:8000

### 优势

- **所有配置外部化**：无需重新构建镜像
- **修改即时生效**：重启容器即可
- **一次构建，到处运行**：镜像与配置解耦

### 技术支持

如有问题，请查看：
- 容器日志：`docker-compose logs web-ui`
- 配置文件：`.env` 和 `config/agent_registry.json`
- 端口占用：`lsof -ti:8000`
