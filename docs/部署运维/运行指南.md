## 🏗️ 系统架构

### 核心组件

1. **Planner 节点** (`distributed_planner_node`)
   - 查询 L3 Agent Registry（当前为 Mock）
   - 使用 LLM（qwq-plus）生成任务分解计划
   - 将 Agent ID 映射到 IP:Port

2. **Executor 节点** (`distributed_executor_node`)
   - 遍历执行计划
   - 通过 HTTP POST 调用远程 Agent（当前为 Mock）
   - 收集执行结果和错误信息

3. **Monitor 节点** (`distributed_monitor_node`)
   - 检查所有任务是否完成
   - 简单的成功/失败判断

4. **Reporter 节点** (`distributed_reporter_node`)
   - 使用 LLM（qwen-max-latest）生成最终报告
   - 汇总执行统计和结果

### 工作流程

```
用户输入 → Planner → Executor → Monitor → Reporter → 最终结果
              ↓          ↓         ↓          ↓
          生成计划  → 远程调用 → 状态检查 → 报告生成
                    (HTTP POST)
```

## 🔧 代码修复记录

在部署过程中修复了以下问题：

### 1. Python 版本兼容性
- ❌ 原问题：`Literal[*OPTIONS]` 语法在 Python 3.9 不支持
- ✅ 解决方案：修改为 `str` 类型，添加兼容注释

### 2. 流式模型调用
- ❌ 原问题：`qwq-plus` 仅支持 `stream=True`
- ✅ 解决方案：
  - 设置 `streaming=True` 参数
  - 使用 `llm.stream()` 收集完整响应
  - 添加非流式回退机制

### 3. 模块导入循环
- ❌ 原问题：导入 `distributed_nodes` 触发 `agents/__init__.py` 加载所有工具（需要 Tavily Key）
- ✅ 解决方案：
  - 修改 `src/agents/__init__.py` 为空导出
  - 修改 `src/graph/__init__.py` 为空导出
  - 直接导入 `llm.py` 模块

### 4. LLM 客户端类型
- ❌ 原问题：`qwq-plus` 使用 `ChatDeepSeek` 但阿里云是 OpenAI 兼容接口
- ✅ 解决方案：改用 `ChatOpenAI` 并配置 DashScope endpoint

import etcd3
client = etcd3.client()

def query_agents(capability: str) -> List[AgentInfo]:
    # 从 etcd 查询符合条件的 Agent
    results = client.get_prefix(f"/agents/{capability}/")
    return [parse_agent_info(r) for r in results]

# 方案2：使用 Redis
import redis
r = redis.Redis()

def query_agents(capability: str) -> List[AgentInfo]:
    keys = r.keys(f"agent:{capability}:*")

**解决**：
```bash

export BASIC_API_KEY=sk-31be252e9dcf413ea4a9ac05ac8b4594
export VL_API_KEY=sk-31be252e9dcf413ea4a9ac05ac8b4594
```

### 问题2：`ModuleNotFoundError: No module named 'browser_use'`

**原因**：使用了 Python 3.9，但 `browser-use` 需要 3.11+

**解决**：
```bash
# 确认使用虚拟环境中的 Python 3.11
./venv/bin/python --version  # 应显示 Python 3.11.x
./venv/bin/python test_distributed.py
```

### 问题3：`ValidationError: Did not find tavily_api_key`

**原因**：运行了 `distributed_main.py` 或导入了原始的 `agents.py`

**解决**：
```bash
# 使用独立测试脚本
./venv/bin/python test_distributed.py

# 或配置 Tavily Key
echo 'TAVILY_API_KEY=tvly-your-key-here' >> .env
```

### 问题4：LLM 返回非 JSON 格式

**原因**：Planner 的 Prompt 不够明确

**解决**：
- 检查 `distributed_nodes.py` 第85-120行的 Prompt
- 确保 LLM 配置了 `response_format={"type": "json_object"}`（如果支持）
