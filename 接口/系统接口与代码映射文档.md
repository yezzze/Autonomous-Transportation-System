| 步骤 | 动作 | 文件路径 | 类/函数 | 说明 |
|------|------|----------|---------|------|

| ② | AW 注册到 ARDC | `src/app/agent_warehouse.py` | `AgentWarehouse._register_to_ardc()` L122 | ⚠️ 骨架：调用 `AgentRegistryClient.register_agent()` |

| HTTP | 对外卸载接口 | `src/api/app.py` | `uninstall_app()` L343 | `DELETE /api/apps/{app_id}` |

**卸载流程**镜像对称：`AppManager.uninstall()` L132 → `AppLogicEngine.uninstall_app_logic()` L70 → `AgentWarehouse.uninstall_agent()` L84 → `AgentWarehouse._deregister_from_ardc()` L152

## 十、设计模式与扩展点

### 设计模式

| 模式 | 应用位置 | 说明 |
|------|----------|------|
| **策略模式** | `AdaptiveOrchestrator` → `get_workflow_builder_for_complexity()` | 按复杂度选择编排策略 |
| **工厂模式** | `AppInfo.create()` / `AgentImage.create()` / `get_llm_by_type()` | 对象创建标准化 |
| **单例模式** | `get_app_manager()` / `get_app_logic_engine()` / `get_registry_client()` | 全局唯一实例 |
| **注册表模式** | `AgentRegistryClient` / `MCPToolRegistry` / `BuiltinToolRegistry` | 统一注册与发现 |
| **命令模式** | `Command(goto=...)` | LangGraph 动态路由，节点返回命令而非直接修改状态 |
| **适配器模式** | `A2AClient` / `MCPClient` | HTTP 到标准协议、stdio 到工具调用的适配 |
| **混入模式** | `LoggedToolMixin` / `@log_io` | 非侵入式日志功能 |

### 扩展点

#### 添加新的 L3 智能体
1. 在 `config/agent_registry.json` 中注册（`id`、`capability`、`ip`、`port`）
2. 实现 A2A 协议的 HTTP 接口（参考 `agent_server.py` 的 `POST /a2a/execute`）
3. 声明 `capability` 和 `description`

#### 添加新的 L1 工具
1. 在 `src/tools/` 创建工具文件，使用 `@log_io` 装饰器
2. 在 `src/tools/__init__.py` 导出
3. 在 `src/config/agents.py` 配置到智能体的 tools 列表

#### 添加新的编排模式
1. 在 `src/graph/` 创建新的 `*_builder.py` 和 `*_nodes.py`
2. 在 `adaptive_orchestrator.py` 的 `get_workflow_builder_for_complexity()` 中注册
3. 编写对应测试

#### 集成新的 MCP 服务器
1. 安装 MCP 服务器（npm 或 pip）
2. 调用 `MCPToolRegistry.register_server(name, command)`
3. 工具通过 `MCPToolRegistry.call_tool()` 自动可用
