# 新对话初始化模板

> 使用方法：复制下方 Prompt，粘贴到新对话的第一条消息，替换 `[...]` 占位符后发送。

---

## 🚀 标准初始化 Prompt（完整版）

```
# 新对话初始化

## 你的角色
你是 LangManus 项目的高级工程师，请完整阅读以下上下文后再开始工作。

## 必读文档（按优先级）
1. CLAUDE.md — 项目规范、工具约定、骨架区域边界、Closing Checklist
2. PROJECT_CONTEXT.md — 项目状态快照、关键设计决策、核心文件路径
3. TASKS.md — 当前 Sprint 任务看板


## 关键约束（本次必须遵守）
- 多文件同步修改用 multi_replace_string_in_file
- 测试命令：PYTHONPATH=. pytest tests/integration/ --ignore=tests/integration/test_bash_tool.py -v --no-header --tb=short --no-cov
- 不要修改骨架区域（RRDC / AW / ASD-Docker / ALCM），见 CLAUDE.md
- 完成后执行 Closing Checklist（更新 PROJECT_CONTEXT.md + TASKS.md）

## 请先确认你理解了以上内容，然后再开始。
```

---

## ⚡ 快速版（已熟悉项目，只说任务）

```
请先读 CLAUDE.md、PROJECT_CONTEXT.md、TASKS.md，然后完成：

[本次任务描述]

完成后执行 Closing Checklist。
```

---

## 📋 Checklist：发送前确认

- [ ] 替换了 `[本次对话目标]` 占位符
- [ ] PROJECT_CONTEXT.md 中"当前正在解决的问题"是最新的
- [ ] TASKS.md 中"进行中"任务反映了本次要做的事

---

## 🔄 对话结束后维护清单

每次对话结束，AI 应自动完成（也可手动检查）：

1. **PROJECT_CONTEXT.md** › `当前正在解决的问题` → 更新为下次起点
2. **PROJECT_CONTEXT.md** › `当前进度` 表格 → 新完成项改为 ✅
3. **PROJECT_CONTEXT.md** › `关键约束与决策` → 追加本次新决策
4. **TASKS.md** → 完成任务移到"已完成"，新待办加入"待办"
5. **接口/当前进度.md** → 对应章节标记 ✅ 已实现

---

## 💡 提示

- `PROJECT_CONTEXT.md` 的"关键约束与决策"是最有价值的部分——每次新决策都要追加，不要覆盖
- `TASKS.md` 记录操作级当前任务；`接口/当前进度.md` 是实现状态档案，两者不重复
- 若对话中途上下文过长，可直接粘贴"快速版"开启续接对话
